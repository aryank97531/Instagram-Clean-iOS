## 👥 Install Side-by-Side (Keep Both Apps!)

You can keep your official App Store Instagram **and** install Instagram Clean side-by-side on the same iPhone!

1. Open **Sideloadly**.
2. Under **Advanced Options**, check the box:  
   `[✓] Use automatic bundle ID`
3. Check `[✓] Change app name:` and name it `Instagram Clean`.
4. Click **Start**.
5. Because Sideloadly generates a unique bundle ID (e.g. `com.burbn.instagram.6JV8M8864F`), iOS installs it as an independent secondary app. Your original Instagram, your photos, and your accounts remain completely untouched!

## 🚀 Quick Start: How to Sideload (3 Minutes)

You do **not** need a jailbroken iPhone. Works on all devices running **iOS 16, 17, or 18**.

### Option 1: Sideloadly (Windows & Mac) — *Easiest & Recommended*

1. **Download the IPA:**  
   Get **`Instagram_Clean.ipa`** from [Releases](https://github.com/aryank97531/Instagram-Clean-iOS/releases).
2. **Download Sideloadly:**  
   Install [Sideloadly](https://sideloadly.io/) (Windows users: install the non-Microsoft Store version of iTunes and iCloud as prompted).
3. **Connect iPhone:**  
   Plug your iPhone into your computer via USB cable.
4. **Deploy:**  
   * Drag `Instagram_Clean.ipa` into Sideloadly.
   * Enter your Apple ID email.
   * Under **Advanced Options**, ensure **`[✓] Use automatic bundle ID`** is checked.
   * Click the blue **Start** button and approve the 2FA prompt on your iPhone.
5. **Trust the Certificate (First Time Only):**  
   * Go to **Settings > General > VPN & Device Management** on your iPhone.
   * Tap your Apple ID under *Developer App* and select **Trust**.
   * *(iOS 16+)*: Go to **Settings > Privacy & Security > Developer Mode**, toggle it **ON**, and reboot your device.

---

### Option 2: AltStore / SideStore

1. Download `Instagram_Clean.ipa` directly in Safari on your iPhone.
2. In **AltStore** or **SideStore**, tap the **+** (Add) button in the *My Apps* tab.
3. Select `Instagram_Clean.ipa` and wait for installation to finish.

---

### Option 3: TrollStore (iOS 14.0 – 17.0)

1. Download `Instagram_Clean.ipa` directly in Safari.
2. Open the Share sheet and select **TrollStore**.
3. Installs permanently with **zero 7-day expiration** and no refresh needed!

## 🛠️ Troubleshooting & Sideloadly Error 9401 Fix

### 🔴 Error 9401: `Failed: (9401) An App ID with Identifier 'com.burbn.instagram2' is not available.`
* **Why this happens:** Apple globally protects registered domain prefixes. `com.burbn.*` belongs to Instagram (Burbn was Instagram's original name). Free developer accounts cannot manually register IDs under `com.burbn.*`.
* **The 5-Second Fix:**
  1. Click **OK** on the Sideloadly error popup.
  2. Under **Advanced Options**, check: **`[✓] Use automatic bundle ID`**.
  3. Click **Start**. Sideloadly will auto-generate a valid unique ID accepted by Apple.

### 🔮 Activating the New Floating "Liquid Glass" UI
Instagram v446 includes Meta's new **`IGLiquidGlassInteractiveTabBar`** (floating glass capsule dock with dynamic blur). 
* **If it doesn't appear on first launch:**  
  When an app is sideloaded into a fresh sandbox, it takes ~15 seconds to download your account's server-side configuration from Meta.
* **The Activation Steps:**
  1. Log into your account in Instagram Clean.
  2. Tap your profile and pull down on your DMs to trigger a server sync.
  3. Swipe up from the bottom of your screen to open the **iOS App Switcher**, swipe Instagram away to **force close** it.
  4. Reopen Instagram. Instagram's cold-boot startup service will load the floating glass dock!

## 🔧 DIY: Customize & Build Your Own IPA

We provide full open-source automation scripts to patch and build the IPA from scratch:

```bash
# 1. Clone the repository
git clone https://github.com/aryank97531/Instagram-Clean-iOS.git
cd Instagram-Clean-iOS

# 2. Inspect or modify toggle flags in scripts/build_clean_ipa.py
python scripts/build_clean_ipa.py
```

### Configurable Preferences in `scripts/build_clean_ipa.py`:
```python
HIDE_REELS_TAB = True         # Completely removes bottom Reels tab
HIDE_EXPLORE_TAB = True       # Completely removes Explore discovery tab
HIDE_ENTIRE_FEED = True       # Suppresses home feed post rendering
PRESERVE_STORIES = True       # Keeps top Stories tray active
GHOST_MODE_STORIES = True     # Anonymous story viewing (no seen receipts)
GHOST_MODE_DMS = True         # Read direct messages without seen receipts
HIDE_TYPING_INDICATOR = True  # Hides 'typing...' in chat
LIQUID_GLASS_UI = True        # Enables modern floating translucent navigation bar
```
